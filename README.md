# Órbita — SaaS de tarefas

Demo estática e standalone de um workspace de tarefas fictício.

## Recursos
- Landing clara e acesso à demonstração sem senha.
- Criar, concluir, excluir, buscar e filtrar tarefas.
- Preços são apenas ilustrativos; não há cobrança, login, backend, coleta ou armazenamento.
- Interface responsiva com navegação lateral em telas maiores.

Abra `index.html` em um navegador moderno.
